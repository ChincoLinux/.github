# ChincoLinux

**Tecnología abierta, libre y comunitaria para las aulas de Chile** 🇨🇱

ChincoLinux es una organización dedicada a llevar el software libre y la tecnología abierta a las aulas de Chile. Creemos que la educación pública merece herramientas libres, accesibles y construidas en comunidad.

We are an open-source community organization taking free software and open technology to Chilean classrooms.

## Modelo operativo / Operating model

ChincoLinux opera bajo la doctrina **[A-Dev](ADEV.md)** (Augmented Development): entregas por PR atómico, commits convencionales, validación con evidencia y mejora disciplinada bajo presión real.

We operate under the A-Dev doctrine: atomic PR-based delivery, conventional commits, evidence-based validation.
