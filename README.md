# ChincoLinux · Meta Repository

Este repositorio no contiene producto: es la **casa administrativa** de la organización ChincoLinux.

## Qué hay aquí / What lives here

| Recurso | Propósito |
|---------|-----------|
| [`profile/README.md`](profile/README.md) | Página pública del perfil de la organización (github.com/ChincoLinux) |
| [`ADEV.md`](ADEV.md) | Doctrina operativa **A-Dev** (canónica a nivel org) |
| [`GOVERNANCE.md`](GOVERNANCE.md) | Modelo de gobernanza y roles |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Guía de contribución (default para todos los repos) |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Código de conducta (default para todos los repos) |
| [`SECURITY.md`](SECURITY.md) | Política de seguridad y reporte de vulnerabilidades |
| [`SUPPORT.md`](SUPPORT.md) | Canales de soporte |

GitHub usa los archivos de este repositorio como **defaults de community health** para todos los repositorios de la organización.

## Flujo de cambios / Change flow

Los cambios a este repositorio siguen la doctrina A-Dev: rama dedicada → PR atómica → revisión de `core-devs` → merge.
